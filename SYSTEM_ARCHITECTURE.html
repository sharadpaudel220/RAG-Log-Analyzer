Agentic RAG System Architecture

INPUT LAYER
Raw System Logs
Unstructured log entries from distributed systems (HDFS, BGL)
HDFS Dataset
Hadoop Distributed File System logs with 11 million entries
BGL Dataset
Blue Gene/L Supercomputer logs with 4.7 million entries
Log Format
Text files containing timestamps, severity levels, and error messages
→
PREPROCESSING
Drain3 Parser
Tree-based algorithm that extracts log templates from unstructured text
Template Extraction
Converts variable parts to wildcards (e.g., "Block blk_123" → "Block <*>")
Severity Detection
Classifies logs by severity: CRITICAL, ERROR, WARN, INFO
Component Identification
Identifies system components (DataNode, NameNode, TaskTracker)
Timestamp Normalization
Standardizes time formats for consistent temporal analysis
→
CORE PROCESSING
Knowledge Base (FAISS)
Vector database with 500+ incident reports using 384-dim embeddings
Retrieval System
Hybrid semantic + keyword search retrieving top-5 relevant documents
LLM Engine (Mistral 7B)
Local language model via Ollama for intelligent log analysis
Temperature Setting
Set to 0.1 for deterministic and consistent outputs
Agentic Controller (ReAct Strategy)
1. THOUGHT: Analyze log context and identify needed information
2. ACTION: Retrieve relevant knowledge from database
3. OBSERVE: Review retrieved information and assess relevance
4. REFLECT: Evaluate confidence (threshold: 0.75) and identify gaps
5. DECIDE: Generate final analysis or iterate (max 5 steps)
→
OUTPUT LAYER
Anomaly Detection
Binary classification: Normal (False) or Anomaly (True)
Severity Classification
Four levels: CRITICAL, HIGH, MEDIUM, LOW
Root Cause Analysis
Identified failure patterns and underlying system issues
Reasoning Chain
Complete thought process with confidence scores for interpretability
Recommendations
Actionable next steps including diagnostic commands and fixes
Source Attribution
References to knowledge base documents used in analysis
