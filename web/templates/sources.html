API Integration Guide

1. Ingest Logs via API

POST /api/ingest
Headers:
  X-API-Key: your-api-key-here
  Content-Type: application/json

Body (single log):
{
  "message": "ERROR: Connection timeout",
  "timestamp": "2024-01-15T10:23:45Z",
  "severity": "ERROR",
  "hostname": "server-01"
}

Body (batch):
[
  {"message": "log 1", "timestamp": "..."},
  {"message": "log 2", "timestamp": "..."}
]

2. Webhook Integration

POST /api/ingest/webhook/{source_id}

Send logs in real-time to the webhook URL.
No authentication required for webhooks.

3. File Upload

POST /api/ingest/upload
Content-Type: multipart/form-data

Form Data:
  file: log_file.log
  source_id: your-source-id
  source_type: system|network|application|security

4. Example: Python Client

import requests

api_key = "your-api-key"
url = "http://localhost:5001/api/ingest"

logs = [
    {
        "message": "ERROR: Database connection failed",
        "timestamp": "2024-01-15T10:23:45Z",
        "severity": "ERROR"
    }
]

response = requests.post(
    url,
    json=logs,
    headers={"X-API-Key": api_key}
)

print(response.json())

5. Example: cURL

curl -X POST http://localhost:5001/api/ingest \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "ERROR: Connection timeout",
    "timestamp": "2024-01-15T10:23:45Z",
    "severity": "ERROR"
  }'
